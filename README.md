# ip文案出稿llm-wiki

> 基于 Karpathy「LLM Wiki」思路的**文案产出模板**——把已沉淀的知识和素材，经 AI 按固定流程稳定地变成一篇篇可发布的公众号 / 口播成品。
> 与「ip知识库搭建llm-wiki」（管**攒**知识）平级，本模板管**产**内容。两者配合：知识库负责「有料可写」，出稿工作台负责「稳定成稿」。

## 解决什么问题
做 IP / 知识付费 / 咨询，最大的坑是**「写了一篇，下一篇不知道写什么、怎么写」**——每次从零开始，慢、不稳定、质量忽高忽低。

这套模板把内容生产**流程化**：选题 → 调素材 → skill 出正文 → 起标题 → 排版 → 交付。AI 按契约走，稳定产出「有个人味道」的成品，而不是每次临时发挥。

## 快速开始
1. Clone 本仓库
2. 把 `template/` 整个复制为你的 Obsidian vault（或 vault 里的一个文件夹）
3. 填 2 个文件（见下）
4. 有选题/素材时丢进 `0-选题池` / `1-素材库`，跟 AI 说「帮我把这个选题写出稿」

## 只需填 2 个文件
- `template/5-个人风格/个人风格文档.md` —— 语言风格 / 金句 / 观点 / 故事 / 私域话术
- `template/5-个人风格/红线话术文档.md` —— AI 一定不说的词

> 这 2 个文件决定「你的味道」，是这份模板里唯一需要你亲手填的部分。填完，AI 写的稿子才像你。

## 目录结构
```
template/
├── 0-选题池/            # 想法、热点、待写选题
├── 1-素材库/            # 从知识库调来的素材
├── 2-内容生产/          # 一选题一文件夹：文章.md + 排版.html
├── 3-标题库/            # 标题公式 + 历史数据规律
├── 4-发布追踪/          # 发布后回填阅读/涨粉数据复盘
├── 5-个人风格/          # 语言风格 + 红线话术（唯一要你填的）
├── SCHEMA.md            # ⭐ 出稿契约（AI 必读）
├── 出稿SOP.md           # 通用 6 步出稿流程
├── wiki-index.md        # 总目录
└── skills/              # 可带的 skill（如标题策略师）
```

## 给别的老师 / 项目定制
复制 `template/` → 只改『5-个人风格』2 个文件 → 就是这个老师的出稿工作台。`0-5` 目录和 `SCHEMA.md` 骨架不动（骨架稳定、风格可换）。

## 作为 Agent Skill 使用
根目录 `SKILL.md` 可直接作为 WorkBuddy / Claude 类 Agent 的 skill 加载。

## 配套建议
- 需要一个「知识库模板」来攒料 → 去用 `ip知识库搭建llm-wiki`
- 本模板假设你**已经有料可写**；没有料的话，先建知识库

## 方法论出处
- 底层思路：Andrej Karpathy 提出的 **LLM Wiki**（compile, not retrieve）
- 出稿流程：内容生产的通用实践整理
