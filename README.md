# ip知识库工作台llm-wiki

> 基于 Karpathy「LLM Wiki」思路的**个人知识库工作台模板**——把一手原始素材，经 AI 编译成你的个人知识体系，再稳定地产出一篇篇可发布的公众号 / 口播成品。
> 一句话：**存 → 编译 → 产出**。

## 解决什么问题
做 IP / 知识付费 / 咨询，最值钱的不是「写」，而是你攒下的一手素材：跟客户聊天、做诊断、踩过的坑、看到的好文章。传统做法是**写的时候临时翻、硬挤**——慢、不稳定、质量忽高忽低。

这套模板把**知识提前编译好**：素材进 `0-原始素材` → AI 编译进 `1-沉淀知识`（形成你的知识体系）→ 写稿时从沉淀知识调用、在 `2-内容生产` 稳定产出成品。

## 快速开始
1. Clone 本仓库
2. 把 `template/` 整个复制为你的 Obsidian vault（或 vault 里的一个文件夹）
3. 填 2 个文件（见下）
4. 一手素材丢进 `0-原始素材`，跟 AI 说「帮我把这个编译进沉淀知识」；要写稿时说「帮我把这个选题写出稿」

## 只需填 2 个文件
- `template/3-个人风格/个人风格文档.md` —— 语言风格 / 金句 / 观点 / 故事 / 私域话术
- `template/3-个人风格/红线话术文档.md` —— AI 一定不说的词

> 这 2 个文件决定「你的味道」，是这份模板里唯一需要你亲手填的部分。填完，AI 写的稿子才像你。

## 三阶结构
```
template/
├── 0-原始素材/         # 第1阶：所有一手素材，只进不出
│   ├── 外部学习/       # 从别人那学来的
│   │   ├── 博主文章/   ├── 公开内容/   └── 学习笔记/
│   ├── 我的经验/       # 自己亲历
│   │   ├── 工具实测/   ├── 实操流程/   └── 案例故事/
│   └── 灵感/           # 冒出来的想法
│       ├── 选题灵感/   └── 金句观点/
├── 1-沉淀知识/         # 第2阶：编译成你的知识体系（统一存放，不分来源）
│   ├── 知识点/   ├── 方法论/   ├── 案例故事/
│   ├── 金句观点/   └── 选题库/
├── 2-内容生产/         # 第3阶：一选题一文件夹：文章.md + 排版.html ★
├── 3-个人风格/         # 语言风格 + 红线话术（唯一要你填的）
├── SCHEMA.md           # ⭐ 核心契约（AI 必读）
├── 出稿SOP.md          # 通用 6 步出稿流程
├── wiki-index.md       # 总目录
└── skills/             # 可带的 skill（如标题策略师）
```

## 给别的老师 / 项目定制
复制 `template/` → 只改『3-个人风格』2 个文件 → 就是他自己的知识库工作台。`0-3` 目录和 `SCHEMA.md` 骨架不动（骨架稳定、味道可换）。

## 作为 Agent Skill 使用
根目录 `SKILL.md` 可直接作为 WorkBuddy / Claude 类 Agent 的 skill 加载。
