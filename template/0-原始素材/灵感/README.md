# 灵感

> 你突然想到的、想沉淀下来的任何内容。先抓住别丢。

## 不建固定分类
灵感是临时的、跳跃的、什么都有可能——一个想法、一个方法、一个念头、一个还没想清楚的连接。**它不一定是选题，也不一定是金句**，所以这里**不设固定子目录**。

## 怎么记：按日期
直接按日期命名记下来，一个日期一个文件（同一天多条就加序号）：
- `2026-08-26_记一个想法.md`
- `2026-08-26_2_又想到的.md`

## 怎么用
跟 AI 说「**帮我记个灵感**」，一句话也行，AI 帮你扩展成文件。
之后需要时，AI 会从这些灵感里提炼，编译进 `1-沉淀知识`。

⛔ 这里只记"你冒出来的想法"，保持原始，不整理、不评判。
