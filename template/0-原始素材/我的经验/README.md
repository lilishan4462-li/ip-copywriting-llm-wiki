# 我的经验

> 自己经历过、亲历过的一切一手素材：会议、业务、交流、案例。先如实记下来，不要加工。

## 二级分类
| 子目录 | 放什么 |
|---|---|
| `会议纪要/` | 开会聊了什么、定了什么 |
| `业务资料/` | 跟业务相关的资料、材料、数据 |
| `交流讨论纪要/` | 跟人交流、讨论碰撞出的东西 |
| `案例故事/` | 真实客户案例、对话、故事 |

## 怎么用
跟 AI 说「**帮我把这个经验记下来**」。
过程、结果、感受都如实记，AI 后续帮你提炼成沉淀知识。

⛔ 不要美化、不要加戏，真实记录。涉及客户隐私的数字、名字按需脱敏，真实但可安全引用。
