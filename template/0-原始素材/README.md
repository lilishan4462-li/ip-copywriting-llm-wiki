# 0 · 原始素材（第 1 阶 · 只进不出）

> ⚠️ **这是整个工作台的第一层，也是最重要的一层。**
> 所有一手素材都先落这里，**只进不出，不要先整理**——整理交给 AI。
> 这里是你所有认知的「ground truth」，AI 只读取、不修改。
> 作者 / 来源 / 日期信息必须保留。

## 按来源分三类
| 子目录 | 放什么 |
|---|---|
| `外部学习/` | 从别人那学来的：博主文章、公开内容、学习笔记 |
| `我的经验/` | 自己的亲历：会议纪要、业务资料、交流讨论纪要、案例故事 |
| `灵感/` | 突然冒出来的想法（不设固定分类，按日期记） |

## 怎么用
跟 AI 说一句「**帮我存进原始素材**」即可，先存进来，AI 后续会编译。

之后 AI 读这里的料 → 提炼 → 编译进 `1-沉淀知识`。

⛔ 关键：**不同来源不要互相掺和**。外部学的、自己经历、灵感，各归各的子目录，方便追溯。
