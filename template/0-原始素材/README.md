# 0 · 原始素材（第 1 阶 · 只进不出）

> ⚠️ **这是整个工作台的第一层，也是最重要的一层。**
> 所有一手素材都先落这里，**只进不出，不要先整理**——整理交给 AI。
> 这里是你所有认知的「ground truth」，AI 只读取、不修改。
> 作者 / 来源 / 日期信息必须保留。

## 按来源分四类
| 子目录 | 放什么 |
|---|---|
| `外部学习/` | 从别人那学来的：博主文章、公开内容、别人的观点 |
| `我的实践/` | 自己亲测、实操、跑过的东西 |
| `灵感/` | 突然冒出来的想法、念头 |
| `真实案例/` | 真实发生过的客户案例、对话、故事 |

## 怎么用
跟 AI 说一句「**帮我存进原始素材**」即可，先存进来，AI 后续会编译。

之后 AI 读这里的料 → 提炼 → 编译进 `1-知识库`。

⛔ 关键：**不同来源不要互相掺和**。外部学的、自己做的、灵感、案例，各归各的子目录，方便追溯。
