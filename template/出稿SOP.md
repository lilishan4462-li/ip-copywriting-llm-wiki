# 文案出稿 SOP

> 本 SOP 覆盖**公众号 / 内容平台长文**的完整出稿流程。
> 一句话流程：**选题 → 调素材 → skill 出正文 → 起标题 → 排版 → 交付**。
> 目标：从沉淀知识素材，产出一篇可发布的文章（含标题和排版）。
>
> 📦 三个 skill 已内置在本模板 `skills/` 下，直接调用即可：
> - 出正文 → **活人感写作**（human-writing）
> - 起标题 → **gzh-title-strategist**（标题策略师）
> - 排版 → **gzh-design-skill**（公众号排版引擎）

## 一、出稿流程（六步）

### 第 1 步：选题，先判断模式
每个选题先判断属于哪种，决定知识来源：

| 模式 | 知识来源 | 例子 |
|---|---|---|
| 外部知识驱动型 | 主要来自沉淀知识 / 学来的素材 | 「行业里的普遍现象」 |
| 个人经验驱动型 | 主要来自个人亲历 / 案例 | 「我亲测了 XX」 |
| 混合型 | 知识解释问题，个人经验负责落地 | 「现象 + 我的解法」 |

判断依据：这次要讲的内容，知识主要来自哪。

### 第 2 步：调素材
读 `1-沉淀知识` 的对应主题，重点取每个知识页里的「出稿素材」区块（一句话观点、开头钩子、核心金句、可展开案例）。

### 第 3 步：活人感写作出正文
正式调用 Skill 工具加载「**活人感写作**」（human-writing）：
- 把第 2 步调出的素材整理成材料清单，喂给 skill。
- skill 先检查材料够不够，够 5 件以上才写长稿；不够它会先问。
- 正文出来是纯文本（不带小标题、不带加粗）。
- 若你换用其他写作 skill，此步替换为你的写作 skill 即可。

### 第 4 步：加排版层（随文章走，克制标注）
在 skill 正文文字**不动**的前提下，加视觉排版：
1. 小标题：一个逻辑块切一个，从正文提炼，不新增内容，无数量标准。
2. 加粗：克制，只标最有冲击力的数据、最关键结论句。
3. 亮点卡：从「核心金句」里挑最能代表全文观点的一句，默认 AI 判断，两句话都合适才问用户。

> 这是「排版层」，不改变 skill 正文文字，只加视觉标记。

### 第 5 步：起标题
正式调用 Skill 工具加载「**gzh-title-strategist**」（标题策略师）：
1. 诊断文章：类型 / 读者 / 一句话结论 / 最强证据。
2. 按点击动机出多组标题（网感 / 稳健 / 数据 / 长期）。
3. 推荐 1 个主标题 + 2 个备选。
4. 外标题（后台标题栏）和封面标题要视角错开。

### 第 6 步：排版 + 交付
正式调用 Skill 工具加载「**gzh-design-skill**」（公众号排版引擎）：
- 把正文（含排版层）喂给 skill，生成可粘贴公众号编辑器的排版 HTML + 预览页。
- 默认用「摸鱼绿」主题，按需换主题或"一键自动排版"。
- 跑 skill 自带校验脚本，ERROR 清零才算完成。
- **交用户确认，不擅自发布。**

## 二、目录规范（一个选题一个文件夹）
```
2-内容生产/
└── YYYY-MM-DD_主题_关键词/
    ├── 文章.md              ← 源稿
    ├── 排版.html            ← 干净正文
    └── 预览.html            ← 带预览，浏览器打开
```

共享文件（发布追踪表 / 选题模板）留在顶层。

## 三、交付标准
- 正文有小标题 + 关键加粗
- 标题有主标题 + 2 备选
- 排版有预览页，校验通过
- 作者签名区用 `{{作者名}}` 占位，交付时提醒用户替换

## 四、平台差异注意
- 不同平台（公众号 / 视频号 / 小红书）排版支持度不同，出稿前先确认目标平台。
- 视频号 / 口播脚本风格与长文不同，建议单独 SOP，不要混用。
