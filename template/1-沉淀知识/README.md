# 1 · 沉淀知识（第 2 阶 · 统库）

> ⚠️ **核心原则：一个统库，不分来源。**
> 所有沉淀下来的知识都放这里，**不区分「学来的」还是「自己验证的」**——学到了、消化了，就都是你的知识。
> **分类只看「出稿用得上什么」，不看「从哪来的」。**

## 为什么按这 5 类分
知识库的最终目的，是**能直接出内容**（公众号文章 / 口播文案）。所以按「AI 写稿时需要什么」来分，写稿时就知道去哪取料：

| 子目录 | 出稿时干什么用 |
|---|---|
| `知识点/` | 讲清"是什么"：概念、原理、现象、事实 |
| `方法论/` | 讲清"怎么做"：方法、步骤、SOP、流程（干货核心） |
| `案例故事/` | 讲清"可信"：真实案例、故事、对话、数据 |
| `金句观点/` | 讲清"好记"：浓缩的判断、金句、记忆点 |
| `选题库/` | 讲清"写什么"：能生出的选题方向 |

## 知识怎么形成
1. AI 读 `0-原始素材` 里的料，提炼核心内容。
2. 按这 5 类归到对应子目录，写成知识页（或按你的习惯建立自己的主题子类）。
3. 多篇重复的知识**合并去重**，避免冗余。
4. 更新 `wiki-index.md`，在 `logs/ingest-log.md` 记一行。
5. 每个知识页保留内部来源，方便回查。

> 这里的知识是**被加工过的**（提炼、合并、整理过），不再是原始素材。
