# 1 · 沉淀知识（第 2 阶 · 统库）

> ⚠️ **核心原则：一个统库，不分来源。**
> 所有沉淀下来的知识都放这里，**不区分「学来的」还是「自己验证的」**——学到了、消化了，就都是你的知识。

## 这里放什么
- 从 `0-原始素材` 编译、提炼、合并后的知识
- 按**主题**组织（一个主题一个知识页，或按你的习惯体系）
- 一个统库统一存放，不按「外部/自己」分目录

## 知识怎么形成
1. AI 读 `0-原始素材` 里的料，提炼核心内容。
2. 按主题整理成知识页（用 `知识页模板.md`）。
3. 多篇重复的知识**合并去重**，避免冗余。
4. 更新 `wiki-index.md`，在 `logs/ingest-log.md` 记一行。
5. 每个知识页保留内部来源，方便回查。

> 这里的知识是**被加工过的**（提炼、合并、整理过），不再是原始素材。
