# 2 · 内容生产（第 3 阶 · 产出）

> 一个选题一个文件夹。这里是一篇篇能发布的成品来源。

## 目录规范
```
2-内容生产/
└── YYYY-MM-DD_主题_关键词/
    ├── 文章.md        ← 源稿
    ├── 排版.html      ← 干净正文
    └── 预览.html      ← 带预览，浏览器打开
```

## 每篇成品包含
- 正文（小标题 + 克制加粗）
- 标题（1 主 + 2 备选）
- 排版 HTML + 预览页

## 注意
- 改文字一定改 `文章.md` 源稿，不要直接改排版 HTML。
- 排版 HTML 是成品，不要用可视化编辑器打开并保存（会弄丢骨架）。
- 出稿前先判断选题模式（外部知识驱动 / 个人实践驱动 / 混合型），再按 SCHEMA 的六步流程走。
