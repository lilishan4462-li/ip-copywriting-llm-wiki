# skills · 内置 skill（已封装好）

> 出稿六步流程需要的三个 skill **全部内置**在本目录，clone 下来即得。
> 使用前先把它们安装（复制）到你的 AI 工具能加载的 skill 目录，见文末「怎么安装」。

## 内置清单

### 1️⃣ 活人感写作（human-writing）
- **用在**：出稿第 3 步，出正文。
- **作用**：通用中文创作与改稿。写出来的文字像「见过事、查过材料的活人」，避免空泛机构腔、营销腔和模型腔；非虚构长文先检查材料够不够，材料不足会追问或缩短，不用灌字数凑数。
- **输入**：第 2 步调出的素材材料清单。
- **输出**：纯文本正文（不带小标题、不带加粗——视觉层由排版步骤加）。

### 2️⃣ gzh-title-strategist（标题策略师）
- **用在**：出稿第 5 步，起标题。
- **作用**：分析文章生成、改写、批评、排序公众号标题；先诊断文章真实价值，再按不同点击动机（稳健 / 网感 / 专业 / 数据 / 长期）出多组标题，最后推荐 1 主标题 + 2 备选。
- **输入**：文章正文（或最完整稿件）。
- **输出**：文章诊断 + 标题策略 + 候选标题 + 前 5 名评分 + 最终推荐 + 风险提示。

### 3️⃣ gzh-design-skill（公众号排版引擎，gzh-design）
- **用在**：出稿第 6 步，排版 + 交付。
- **作用**：把 Markdown 正文转成可直接粘贴公众号编辑器的 HTML。自动章节编号、关键词标记、引言卡、目录导航、代码块、图片、作者签名；内置多套主题（默认推荐「摸鱼绿」），支持一键自动排版和自定义主题；附带校验脚本，ERROR 清零才算完成。
- **输入**：第 4 步加完排版层的正文（Markdown）。
- **输出**：`排版.html`（干净成品）+ 预览页。

## 怎么安装
把上面每个 skill 文件夹整体复制到你的 AI 工具加载 skill 的位置：
- Claude Code / Claudian → 复制到 `~/.claude/skills/`（全局）或项目根的 `.claude/skills/`
- WorkBuddy 等 Agent → 按它的 skill 目录说明放置

安装后跟 AI 说「调用 活人感写作 / 标题策略师 / 公众号排版」即可触发对应 skill。

## 想换自己的 skill？
三个 skill 各自独立，替换任何一个都不影响流程：
- 换写作 skill → 替换第 3 步
- 换标题 skill → 替换第 5 步
- 换排版 skill → 替换第 6 步

只要产出物一致（纯文本正文 / 主副标题 / 可粘贴 HTML），SOP 流程照跑。
