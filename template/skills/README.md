# skills · 可带的 skill

> 这里是出稿时用到的通用 skill。每个都是一个独立、可复用的能力。
> 复制到你的 Obsidian vault 里的 `.claude/skills/` 或指定 skill 目录即可被调用。

## 已有 skill

### gzh-title-strategist（标题策略师）
- **作用**：分析文章，生成、改写、批评、排序公众号标题。
- **怎么用**：出稿起标题时调用。它会先诊断文章，再按不同点击动机生成多组标题，最后推荐 1 主标题 + 2 备选。
- **输入**：文章正文（或用户提供的最完整稿件）。
- **输出**：文章诊断 + 标题策略 + 候选标题 + 评分 + 最终推荐 + 风险提示。

## ⚠️ 出稿还需要 2 个 skill（本模板未内置，需你补）
按 SCHEMA 的六步出稿流程，完整跑通还需要：

### 1. 写作 skill（出正文用）
- **作用**：从素材生成一篇有「人味」的正文（纯文本）。
- **建议**：用「活人感写作」类 skill，或你习惯的写作方法。
- 没有它 → 第 3 步「skill 出正文」会断，只能 AI 硬写。

### 2. 排版 skill（出排版 HTML 用）
- **作用**：把正文生成平台兼容的排版 HTML（带复制按钮、预览页）。
- **建议**：用能在公众号粘贴不坏的排版 skill。
- 没有它 → 第 6 步「排版 + 交付」会断。

> 这两个 skill 我没内置，是因为不同人习惯不同、且不是本模板的通用骨架。你要用的话单独加进来。
