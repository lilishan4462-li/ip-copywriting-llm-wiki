# 标题库

> 出稿起标题时，调用「skills/gzh-title-strategist」（标题策略师）。
> 本文是给本账号的「标题速查」。

## 通用标题公式（来自标题 skill）

### 教程 / 工作流
- `[时间]用[工具]做出[成果]（附[资源]）`
- `从0到1搭建[系统]：[数量]步跑通[流程]`
- `不用[门槛]，[时间]就能[具体结果]`

### 行业经验 / 案例
- `做了[年数]年[行业]，我最后悔的是[教训]`
- `我们花了[代价]才明白：[结论]`
- `[岗位]真正拉开差距的，不是[常见认知]`

### 观点输出
- `别再[常见做法]了，真正决定[结果]的是[观点]`
- `[现象]看起来很强，但可能只是[反方结论]`
- `我越来越相信：[核心判断]`

## 起标题流程（调用 skill 时）
1. 诊断文章：类型 / 读者 / 一句话结论 / 最强证据 / 可带走交付物。
2. 按不同点击动机生成：稳健 / 网感 / 专业 / 数据 / 长期。
3. 评分（点击欲望 / 事实匹配 / 人群匹配 / 差异化 / 长期价值）。
4. 推荐 1 主标题 + 2 备选。
